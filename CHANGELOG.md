# Changelog

Все заметные изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0b]

### Добавлено
- Автоматическая проверка обновлений через GitHub (`/api/check-update`, `/api/update-ota`)
- OTA-обновление по URL (кнопка «Обновить автоматически» в веб-интерфейсе)
- Скрипты быстрой прошивки: `flash_flook32.bat` (Windows), `flash_flook32.sh` (Linux/macOS)
- Поиск устройства в сети: `tools/find_flook32.bat`
- Логирование потери/восстановления связи с Klipper в журнал ошибок
- Контроль фрагментации кучи с авторебутом при утечке памяти
- Логирование состояния памяти (критическое/низкое/восстановление) в журнал ошибок
- Улучшенные LED-анимации: волна Wi-Fi, дыхание, мерцание, прогресс
- Дисклеймер с 10-секундной блокировкой экрана в режиме точки доступа
- Скрипты сборки веб-ресурсов с автоскачиванием Chart.js (`compress_webui.sh`, `compress_webui.bat`)
- Структура репозитория: `docs/`, `firmware/`, `tools/`, `klipper/`, `hardware/`, `enclosure/`
- Полная документация: BUILD, SETUP, WIRING, BOM, FAQ, WEBUI, FIRMWARE, KLIPPER, ESP01S_FIRMWARE

### Изменено
- Проверка доступности Klipper через TCP (вместо UDP) — статус сбрасывается через 60 сек
- Увеличена надёжность определения IP Klipper из NVS (восстановление без автоматического `detected = true`)
- Улучшена документация: перекрёстные ссылки «На главную», быстрая навигация

### Исправлено
- Бесконечное «воскрешение» статуса Klipper через UDP и NVS
- Сброс `klipperStatus.detected` теперь работает корректно
- Убран спам статистики в лог ошибок каждые 5 минут

## [0.1.0b] - 2026-05-20

### Первый публичный релиз
- Двухконтурное управление с гистерезисом (воздух + нагреватель)
- 7 независимых защит с трёхступенчатой эскалацией
- Самообучаемая термальная модель
- Автоматическая адаптация (9 фаз самонастройки)
- Веб-интерфейс на WebSocket + REST API (30+ эндпоинтов)
- Интеграция с Klipper/Moonraker (UDP-обнаружение, автоотключение после печати)
- Аппаратный watchdog на ESP-01S
- LED-индикация на WS2812B (10 режимов)
- Звуковая индикация через бипер (3 мелодии)
- OTA-обновление прошивки
- Библиотеки Chart.js встроены в прошивку (не зависят от CDN)
- IP Klipper сохраняется в NVS и восстанавливается после перезагрузки
- Логирование причины перезагрузки в журнал ошибок
- Проверка свободного места в NVS при старте
- Лицензия GPLv3
