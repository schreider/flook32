## 0. 🚀 Быстрая прошивка

Если не хотите разбираться с Arduino IDE, воспользуйтесь готовыми скриптами из папки `firmware/esp01s_watchdog/`:

**Windows:**
1. Подключите ESP-01S к программатору с перемычкой GPIO0-GND
2. Запустите `flash_esp01s.bat` двойным щелчком

**Linux/macOS:**
1. Подключите ESP-01S к программатору с перемычкой GPIO0-GND
2. Сделайте скрипт исполняемым и запустите:
   ```bash
   chmod +x flash_esp01s.sh
   ./flash_esp01s.sh
   ```

Скрипты установят `esptool` (если нужно), скачают прошивку из репозитория и прошьют устройство.

> 💡 **Совет:** если скрипт не может найти или прошить ESP-01S:
> - Проверьте перемычку GPIO0-GND (режим прошивки)
> - Используйте основные USB с материнской платы ПК, не используйте USB-хаб.

## 1. Общая информация

### Назначение

ESP-01S выполняет роль аппаратного watchdog — независимого контроллера, который отключает питание 220В нагревателя, если основной ESP32 (FLOOK32) завис или вышел из строя.

### Ключевые особенности

* Полная независимость от основной прошивки — работает на отдельном микроконтроллере
* Аппаратное прерывание по фронту сигнала heartbeat
* Требуется 3 последовательных импульса для включения реле
* Автоматическое отключение реле через 6 секунд после пропадания сигнала
* Защита от случайных помех и ложных срабатываний
* Сторожевой таймер ESP8266 для самовосстановления

### Целевая платформа

* ESP-01S (ESP8266)
* Flash: 1MB
* Ядро: Tensilica L106 32-bit, 80 МГц

### Зависимости

Нет внешних библиотек. Используются только встроенные функции Arduino Core для ESP8266:

* `attachInterrupt()` — аппаратное прерывание
* `ICACHE_RAM_ATTR` — размещение ISR в RAM для стабильности
* `ESP.wdtFeed()` — сброс программного watchdog ESP8266

## 2. Аппаратная часть

### Таблица GPIO пинов

| Пин | Назначение | Направление | Примечание |
|-----|-----------|-------------|------------|
| GPIO0 | Реле (питание 220В) | OUTPUT | HIGH = реле замкнуто, LOW = разомкнуто |
| GPIO2 | Heartbeat вход | INPUT | Прерывание по RISING (LOW→HIGH) |

### Схема подключения

```
FLOOK32 (ESP32)                    ESP-01S (ESP8266)                Нагрузка
┌──────────────┐                  ┌──────────────┐              ┌──────────┐
│              │                  │              │              │          │
│  GPIO26 ─────┼──────────────────┼  GPIO2       │              │  220V    │
│  (heartbeat) │   импульс каждые │  (вход)      │     NO  ─────┼──────────┤
│              │   1000 мс        │              │   (реле)     │          │
│              │                  │              │              │ Нагрева- │
│              │                  │              │              │ тель     │
└──────────────┘                  └──────────────┘              └──────────┘
```

### Принцип работы реле

* Реле нормально-разомкнутое (NO)
* HIGH на GPIO0 → реле замкнуто → 220В подаётся на нагреватель
* LOW на GPIO0 → реле разомкнуто → 220В отключено

## 3. Принцип работы

### Алгоритм

```
1. При старте реле ВЫКЛЮЧЕНО (безопасное состояние)
2. Ожидание импульсов от FLOOK32 на GPIO2
3. Получено 3 импульса подряд с интервалом < 5 секунд → реле ВКЛЮЧЕНО
4. Импульсы продолжают приходить → реле остаётся ВКЛЮЧЕНО
5. Импульсы пропали на 6 секунд → реле ВЫКЛЮЧЕНО
6. Возврат к шагу 2
```

### Почему 3 импульса?

Защита от случайного включения при помехах или кратковременных наводках на линию. Одиночный всплеск не включит реле.

### Почему 6 секунд?

FLOOK32 отправляет импульс каждые ~1000 мс (100 мс HIGH + 900 мс LOW). Если ESP32 зависла:
* Последний импульс уходит
* Через 6 секунд ESP-01S гарантированно обнаруживает пропадание (даже с запасом на джиттер)
* Реле отключается

## 4. Структура прошивки (setup + loop)

### 4.1 setup()

```
1. pinMode(RELAY_PIN, OUTPUT)
   └─ digitalWrite(RELAY_PIN, RELAY_OFF) — реле выключено
   └─ delay(200) — стабилизация пина

2. pinMode(HEARTBEAT_PIN, INPUT)
   └─ Настройка пина как вход для heartbeat сигнала

3. lastPulseTime = millis()
   └─ Инициализация таймера последнего импульса

4. attachInterrupt(digitalPinToInterrupt(HEARTBEAT_PIN), onPulse, RISING)
   └─ Прерывание по фронту LOW→HIGH на GPIO2
   └─ ISR: onPulse() — устанавливает pulseFlag = true
```

### 4.2 loop()

```
1. ESP.wdtFeed()
   └─ Сброс программного watchdog ESP8266 (~3.2 сек таймаут)

2. Обработка флага прерывания:
   └─ if (pulseFlag):
       ├─ Сброс флага
       ├─ Проверка интервала с прошлым импульсом
       │   ├─ < 5 сек → consecutivePulses++
       │   └─ ≥ 5 сек → consecutivePulses = 1 (начало новой серии)
       └─ Обновление lastPulseTime

3. Проверка таймаута сигнала:
   └─ if (now - lastPulseTime > 6000 мс):
       └─ consecutivePulses = 0 (сброс счётчика)

4. Принятие решения о реле:
   └─ shouldRelayOn = (consecutivePulses >= 3)
   └─ if (shouldRelayOn != relayState):
       └─ setRelay(shouldRelayOn) — переключение при изменении

5. delay(20) — минимальная задержка для стабильности
```

## 5. Тайминги и константы

| Константа | Значение | Описание |
|-----------|----------|----------|
| SIGNAL_LOSS_TIMEOUT_MS | 6000 мс | Время без сигнала до отключения реле |
| PULSE_TIMEOUT_MS | 5000 мс | Максимальный интервал между импульсами |

### Расчёт таймаутов

**Интервал heartbeat от FLOOK32:**
```
heartbeatPulseMs + heartbeatPauseMs = 100 + 900 = 1000 мс
```

**SIGNAL_LOSS_TIMEOUT_MS (6000 мс):**
```
6 × 1000 мс = 6 пропущенных импульсов
Достаточно для гарантированного детектирования зависания
с запасом на случайную задержку передачи
```

**PULSE_TIMEOUT_MS (5000 мс):**
```
5 × 1000 мс = 5 интервалов heartbeat
Если между импульсами прошло больше — считаем что серия прервалась
```

## 6. Обработка прерываний

### 6.1 ISR (Interrupt Service Routine)

```cpp
ICACHE_RAM_ATTR void onPulse()
{
    pulseFlag = true;
}
```

**ICACHE_RAM_ATTR** — размещает функцию в оперативной памяти (IRAM), а не во flash. Это критически важно для стабильной работы прерываний на ESP8266, так как flash-память может быть занята в момент срабатывания прерывания.

### 6.2 Обработка в loop()

Обработка флага вынесена в основной цикл, а не в ISR, чтобы:
* Не блокировать другие прерывания
* Избежать длительных операций в контексте прерывания
* Иметь доступ ко всем переменным без volatile

## 7. Управление реле

### 7.1 Функция setRelay()

```cpp
void setRelay(bool on)
{
    digitalWrite(RELAY_PIN, on ? RELAY_ON : RELAY_OFF);
    relayState = on;
}
```

* `on = true` → реле замкнуто (220В подано)
* `on = false` → реле разомкнуто (220В отключено)

### 7.2 Безопасное состояние

При старте реле всегда выключено:
```cpp
digitalWrite(RELAY_PIN, RELAY_OFF);  // RELAY_OFF = LOW
```

Это гарантирует, что после перезагрузки ESP-01S нагреватель не включится самопроизвольно.

### 7.3 Переключение только при изменении

```cpp
if (shouldRelayOn != relayState) {
    setRelay(shouldRelayOn);
}
```

Предотвращает излишние переключения реле, продлевая его ресурс.

## 9. Совместимость с FLOOK32

### 9.1 Параметры heartbeat в FLOOK32

Для корректной работы с ESP-01S watchdog в конфигурации FLOOK32 должны быть установлены:

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| heartbeatPulseMs | 100 мс | Длительность импульса должна быть достаточной для детектирования прерыванием |
| heartbeatPauseMs | 900 мс | Суммарный период 1000 мс гарантирует 6 импульсов за 6 секунд |

### 9.2 Условия генерации heartbeat (со стороны FLOOK32)

Heartbeat генерируется только когда:
* `targetTemp > 0` (есть цель по температуре)
* Нет критических ошибок
* Система не заблокирована
* Датчики исправны

Если нагрев выключен или система в аварии — heartbeat не генерируется, реле размыкается.

### 9.3 Проверка работоспособности

1. Загрузите прошивку на ESP-01S
2. Подключите к FLOOK32 по схеме
3. Установите целевую температуру > 0°C
4. Реле должно включиться через ~3 секунды (3 импульса)
5. Отключите нагрев — реле должно отключиться через 6 секунд

## 10. Поиск неисправностей

| Симптом | Возможная причина | Решение |
|---------|-------------------|---------|
| Реле не включается | Нет сигнала heartbeat от FLOOK32 | Проверить провод GPIO26 → GPIO2, проверить импульсы |
| Реле не включается | Помехи на линии | Укоротить провод, экранировать провод |
| Реле включается с задержкой | Слишком длинный интервал heartbeat | Проверить heartbeatPauseMs в FLOOK32 |
| Реле отключается самопроизвольно | Нестабильный heartbeat | Проверить стабильность работы ControlTask в FLOOK32 |
| Реле не отключается при зависании | Завис сам ESP-01S | Программный watchdog ESP8266 перезагрузит ESP-01S через ~3.2 сек |
