## Высоковольтный отсек (220В)

```
╔══════════════════════════════════════════════════════════════════════════════════╗
║               ВЫСОКОВОЛЬТНЫЙ ОТСЕК (220В)                ║    Внутренний блок    ║
╠══════════════════════════════════════════════════════════╣                       ║
║                                                          ║                       ║
║   C8 ── L ───── Шина L ──┬── БП 5В (L)                   ║                       ║
║   (розетка)              ├── БП 12В (L)                  ║                       ║
║    │                     └── ESP01S COM                  ║                       ║
║    │                                                     ║                       ║
║    └─────────── N ── KCD11 ── Шина N ──┬── БП 5В (N)     ║                       ║
║                                        ├── БП 12В (N)    ║                       ║
║                                        └── SSR A1        ║                       ║
║                                                          ║                       ║
║   SSR B1 ───────────────────────────────────────────────── KSD9700 ─ Нагреватель ║
║   ESP01S NO ─────────────────────────────────────────────────────────────┘       ║
║                                                          ║                       ║
║ При пропадании heartbeat > 6 секунд:                     ║                       ║
║ ESP01S реле размыкается → нагреватель обесточивается     ║                       ║
║                                                          ║                       ║
╚══════════════════════════════════════════════════════════════════════════════════╝
```

### Элементы высоковольтного отсека

| Обозначение | Компонент | Назначение |
|-------------|-----------|------------|
| C8 | Разъём IEC C8 | Вход 220В на корпусе |
| KCD11 | Кнопка KCD11 | Разрыв нейтрали 220В |
| Шина L | Шина 220В (фаза) | Распределение фазы |
| Шина N | Шина 220В (нейтраль) | Распределение нейтрали |
| БП 5В | Блок питания 5В/2A | Питание ESP32 и периферии |
| БП 12В | Блок питания 12В/1A | Питание MOSFET и вентилятора |
| SSR | G3MB-202P / SSR-10DA | Твердотельное реле управления нагревателем |
| ESP01S | ESP01S + релейный модуль | Аппаратный watchdog |

### Низковольтный отсек (5В/12В)

```
╔════════════════════════════════════════════════════════════════════════════════════════════╗
║                       НИЗКОВОЛЬТНЫЙ ОТСЕК (5В/12В)                   ║   Внутренний блок   ║
╠══════════════════════════════════════════════════════════════════════╣                     ║
║                                                                      ║                     ║
║   ╔═══════════════╗                                                  ║                     ║
║   ║   ШИНА 5В     ║                                                  ║                     ║
║   ╠═══════════════╣                                                  ║                     ║
║   ║ БП 5В ── VCC ──── ESP32, MAX6675, DS18B20, LED, SSR DC+, ESP01S  ║                     ║
║   ║ БП 5В ── GND ─┬── ESP32, MAX6675, DS18B20, LED, SSR DC-, ESP01S  ║                     ║
║   ║               └── MOSFET, Бипер, Кнопка                          ║                     ║
║   ╚═══════════════╝                                                  ║                     ║
║                                                                      ║                     ║
║   ╔═══════════════╗                                                  ║                     ║
║   ║      12В      ║                                                  ║                     ║
║   ╠═══════════════╣                                                  ║                     ║
║   ║ БП 12В ── +12V ── MOSFET (+)  ───────────────────────────────────── Вентилятор (+12В)  ║
║   ║ БП 12В ── -12V ── MOSFET (-)                                     ║                     ║
║   ║                   MOSFET LOAD ───────────────────────────────────── Вентилятор (-12В)  ║
║   ╚═══════════════╝                                                  ║                     ║
║                                                                      ║                     ║
╚════════════════════════════════════════════════════════════════════════════════════════════╝
```

### Элементы низковольтного отсека

| Обозначение | Компонент | Назначение |
|-------------|-----------|------------|
| ESP32 | ESP32 Dev Board | Основной контроллер |
| MAX6675 | MAX6675 модуль | Преобразователь термопары |
| DS18B20 | Датчик DS18B20 | Температура воздуха в камере |
| LED | LED лента WS2812B | Светодиодная индикация |
| SSR DC+ | SSR G3MB-202P DC+ | Питание реле (5В) |
| SSR DC- | SSR G3MB-202P DC- | Питание реле (5В) |
| MOSFET | MOSFET LR7843 | ШИМ-управление вентилятором |
| Бипер | KY-012 | Звуковая индикация |
| Кнопка | Тактовая кнопка | Сброс к заводским настройкам |

### Сигналы ESP32

```
╔═══════════════════════════════════════════════════════════════════════════════╗
║                              СИГНАЛЫ ESP32                                    ║
╠═══════════════════════════════════════════════════════════════════════════════╣
║                                                                               ║
║   ┌─────────┐    ┌──────────────┐    ┌─────────────────────────────────────┐  ║
║   │ GPIO32  │ →  │ SSR CH1      │    │ Управление нагревателем             │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO33  │ →  │ MOSFET PWM   │    │ ШИМ вентилятора (17 кГц)            │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO26  │ →  │ ESP01S GPIO2 │    │ Heartbeat (100/900 мс)              │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO21  │ →  │ DS18B20 DAT  │    │ OneWire шина                        │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO18  │ →  │ MAX6675 SCK  │    │ Тактирование SPI                    │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO5   │ →  │ MAX6675 CS   │    │ Chip Select                         │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO19  │ ←  │ MAX6675 SO   │    │ Данные SPI                          │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO25  │ →  │ Бипер        │    │ Звуковая индикация                  │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO27  │ →  │ LED DIN      │    │ NeoPixel WS2812B                    │  ║
║   ├─────────┤    ├──────────────┤    ├─────────────────────────────────────┤  ║
║   │ GPIO17  │ ←  │ Кнопка RESET │    │ Сброс к заводским (5 сек)           │  ║
║   └─────────┘    └──────────────┘    └─────────────────────────────────────┘  ║
║                                                                               ║
╚═══════════════════════════════════════════════════════════════════════════════╝
```

### Таблица GPIO

| Пин ESP32 | Направление | Куда | Сигнал | Примечание |
|-----------|-------------|------|--------|------------|
| GPIO32 | → | SSR CH1 | HIGH = включён | Управление нагревателем |
| GPIO33 | → | MOSFET PWM | 0-1023, 17 кГц | ШИМ вентилятора |
| GPIO26 | → | ESP01S GPIO2 | 100/900 мс | Heartbeat watchdog |
| GPIO21 | → | DS18B20 DAT | OneWire | Температура воздуха |
| GPIO18 | → | MAX6675 SCK | SPI | Тактирование |
| GPIO5  | → | MAX6675 CS | SPI | Выбор чипа |
| GPIO19 | ← | MAX6675 SO | SPI | Данные термопары |
| GPIO25 | → | Бипер | HIGH = писк | Звуковая индикация |
| GPIO27 | → | LED DIN | NeoPixel | Светодиодная лента |
| GPIO17 | ← | Кнопка RESET | INPUT_PULLUP | Сброс к заводским (5 сек) |

## Таблица соединений

### Вход 220В и шины

| Откуда | Куда | Примечание |
|--------|------|------------|
| C8 L | Шина L | Фаза 220В |
| C8 N | KCD11 вход | Нейтраль 220В через выключатель |
| KCD11 выход | Шина N | Нейтраль после разрыва |

### Питание блоков от шин 220В

| Откуда | Цвет | Куда |
|--------|------|------|
| Шина L | 🔴 | БП 5В (вход L) |
| Шина N | ⚫️ | БП 5В (вход N) |
| Шина L | 🔴 | БП 12В (вход L) |
| Шина N | ⚫️ | БП 12В (вход N) |
| Шина L | 🔴 | ESP01S COM |
| Шина N | ⚫️ | SSR A1 |

### Шины VCC и GND (5В)

| Откуда | Куда |
|--------|------|
| БП 5В VCC | Шина VCC |
| БП 5В GND | Шина GND |

### Питание модулей от шины VCC (🔴)

| Откуда | Куда |
|--------|------|
| Шина VCC | ESP32 |
| Шина VCC | MAX6675 |
| Шина VCC | DS18B20 |
| Шина VCC | LED WS2812B |
| Шина VCC | SSR DC+ |
| Шина VCC | ESP01S |

### Земля модулей от шины GND (⚫️)

| Откуда | Куда |
|--------|------|
| Шина GND | ESP32 |
| Шина GND | MAX6675 |
| Шина GND | DS18B20 |
| Шина GND | MOSFET LR7843 |
| Шина GND | Бипер KY-012 |
| Шина GND | LED WS2812B |
| Шина GND | Кнопка RESET |
| Шина GND | SSR DC- |
| Шина GND | ESP01S |

### Питание 12В

| Откуда | Цвет | Куда |
|--------|------|------|
| БП 12В +12В | 🔴 | MOSFET +12В |
| БП 12В −12В | ⚫️ | MOSFET −12В |

### GPIO сигналы ESP32

| GPIO19 | SO | MAX6675 SO |

| GPIO25 | — | Бипер KY-012 |
