## 0. 🚀 Быстрая прошивка

### 0.1 Windows

Если Вы не хотите разбираться в Arduino IDE, воспользуйтесь готовым скриптом из папки `tools/`:

1. Скачайте скрипт прошивки из репозитория: [flash_flook32.bat](../tools/flash_flook32.bat)
2. Подключите ESP32 к компьютеру по USB
3. Запустите скрипт двойным щелчком

Скрипт сам скачает `esptool.exe`, загрузит актуальную прошивку из релиза и прошьёт устройство. Никаких дополнительных действий не требуется.

> 💡 **Совет:** если скрипт не может найти ESP32:
> - Переведите плату в режим загрузки: зажмите **BOOT**, нажмите и отпустите **EN**, затем отпустите **BOOT**
> - Убедитесь, что установлен драйвер CH340/CP210x ([скачать драйвер CH340](https://www.wch.cn/downloads/CH341SER_EXE.html))
> - Используйте USB-кабель с передачей данных (не только для зарядки)
> - Используйте основные USB-порты на ПК, не используйте USB-хабы. 

### 0.2 🐧 Linux/macOS

Для Linux и macOS используйте bash-скрипт:

1. Скачайте скрипт прошивки из репозитория: [flash_flook32.sh](../tools/flash_flook32.sh)
2. Подключите ESP32 к компьютеру по USB
3. Сделайте скрипт исполняемым и запустите:
   ```bash
   chmod +x tools/flash_flook32.sh
   ./tools/flash_flook32.sh
   ```

Скрипт установит `esptool.py` через pip, скачает прошивку и прошьёт устройство.

> 💡 **Совет:** если скрипт не может найти ESP32:
> - Проверьте права доступа к порту: `sudo usermod -a -G dialout $USER` (Linux)
> - На macOS драйверы CH340/CP210x встроены в систему
> - Переведите плату в режим загрузки: зажмите **BOOT**, нажмите и отпустите **EN**, затем отпустите **BOOT**
> - Проверьте, что порт виден в системе: `ls /dev/ttyUSB* /dev/ttyACM* /dev/cu.*`

## 1. Прошивка ESP32

### 1.1 Установка Arduino IDE

1. Скачайте и установите [Arduino IDE](https://www.arduino.cc/en/software)
2. Откройте Arduino IDE

### 1.2 Добавление поддержки ESP32

1. **Файл → Настройки** → в поле **Дополнительные ссылки для менеджера плат** вставьте:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
2. **Инструменты → Плата → Менеджер плат** → найдите **ESP32** → установите

### 1.3 Установка библиотек

**Скетч → Подключить библиотеку → Менеджер библиотек** → установите:

| Библиотека | Автор | Назначение |
|------------|-------|------------|
| Adafruit NeoPixel | Adafruit | LED лента WS2812B |
| OneWire | Jim Studt, Tom Polland, Robin James | Шина для DS18B20 |
| DallasTemperature | Miles Burton | Датчик DS18B20 |
| ArduinoJson | Benoit Blanchon | Парсинг JSON |
| ESPAsyncWebServer | ESP32Async | Веб-сервер |
| AsyncTCP | ESP32Async | Асинхронный TCP |

### 1.4 Компиляция и загрузка

1. Скачайте [архив проекта](https://github.com/schreider/flook32) и распакуйте
2. Откройте `firmware/flook32/flook32.ino` в Arduino IDE
3. **Инструменты → Плата → ESP32 → ESP32 Dev Module**
4. **Инструменты → Порт** → выберите порт (`COMx` на Windows, `/dev/ttyUSB0` на Linux)
5. **Инструменты → Partition Scheme → Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)**

   <details>
   <summary>❓ Почему именно эта схема разделов?</summary>

   - **Два раздела приложений** `app0` и `app1` нужны для OTA-обновлений без проводов
   - **1.9 МБ на раздел** — достаточно для всей прошивки с запасом на доработки
   - **SPIFFS почти не используется** — конфигурация в NVS (Preferences), веб-интерфейс в PROGMEM
   - Схема работает на ESP32 с 8 и 16 МБ флеша без изменений в коде

   **Почему веб-интерфейс в PROGMEM, а не в файловой системе?**

   - **Мгновенная отдача** — без пауз на сборку мусора и поиск файла в SPIFFS
   - **Защита от сбоев питания** — PROGMEM это часть прошивки, не меняется во время работы
   - **Экономия RAM** — HTML лежит во Flash и не фрагментирует кучу
   - **Атомарные обновления** — интерфейс и API всегда одной версии
   - **Никаких лишних шагов** — открыл проект, нажал «Загрузить», всё готово
   </details>

6. Нажмите **Загрузить** (стрелка вправо)

### 1.5 Самостоятельная сборка веб-ресурсов

Готовые скрипты в папке `firmware/flook32/` делают всё автоматически:

- Скачивают недостающие исходники (`index.html`, `favicon.ico`, `icon_192.png`) из репозитория
- Скачивают актуальные версии **Chart.js** и **адаптера** с CDN
- Сжимают все ресурсы в GZIP
- Создают `.h` файлы для прошивки

| Исходник | Результат | Когда пересобирать |
|----------|-----------|--------------------|
| `src/index.html` | `index_html_gz.h` | При изменении веб-интерфейса |
| `src/favicon.ico` | `favicon_ico.h` | При замене иконки браузера |
| `src/icon_192.png` | `icon_192_png_gz.h` | При замене иконки для смартфонов |
| Chart.js (CDN) | `chart_min_js_gz.h` | Автоматически при каждом запуске |
| Адаптер (CDN) | `chartjs_adapter_gz.h` | Автоматически при каждом запуске |

**Запуск:**

- **Linux/macOS:** `./compress_webui.sh`
- **Windows:** двойной щелчок по `compress_webui.bat`

После выполнения скрипта перекомпилируйте прошивку.

## 2. Первый запуск

### 2.1 Подключение к точке доступа

1. После прошивки ESP32 создаст точку доступа:
   - **SSID:** `FLOOK32-XXXX` (XXXX — ID устройства)
   - **Пароль:** `flook1234`
2. Подключитесь к этой сети с телефона или компьютера
3. Откройте браузер → `http://192.168.4.1`

### 2.2 Настройка Wi-Fi

1. В веб-интерфейсе откроется вкладка **Wi-Fi**
2. Дождитесь автоматического сканирования сетей
3. Выберите свою домашнюю сеть → введите пароль → **Подключиться**

### 2.3 Переход на домашний IP

1. После подключения к роутеру устройство получит IP-адрес и покажет его на странице `192.168.4.1`
2. Нажмите **Перейти** — произойдёт редирект и перезагрузка устройства, точка доступа отключится
3. В дальнейшем заходите в веб-интерфейс по этому IP

> **📌 Сохраните IP:**
> - Добавьте страницу в закладки браузера
> - Закрепите IP за устройством в роутере (DHCP reservation), иначе адрес может измениться после перезагрузки

### 2.4 Если вы потеряли IP-адрес

#### Через Klipper (рекомендуемый)

Если установлен плагин `flook32.py`, выполните в консоли Klipper:
```gcode
FLOOK_STATUS
```

#### Через BAT-скрипт (Windows)

Запустите скрипт из папки `tools/` двойным щелчком:
```
find_flook32.bat
```
Скрипт просканирует локальную сеть, найдёт устройство и автоматически откроет веб-интерфейс в браузере.

> Если ничего не помогло — подключитесь к точке доступа `FLOOK32-XXXX` (пароль `flook1234`) и откройте `http://192.168.4.1`.
